# pöytä

pöytä (Finnish for "table") is a networked board game system that aims to be almost universal: it doesn't implement individual games, but lets players use the images they want as assets, along with the most common mechanisms of board games: movable pieces, cards, dice, and so on.

It ran on GNU/Linux, Mac OS X and Windows. `main` is the wxWidgets branch (2010); the `pre-wx` branch is the earlier line, released as 0.5.

It was imported from Launchpad (Bazaar) in 2026, with its full history.

The original release archives are in the [releases](../../releases).
